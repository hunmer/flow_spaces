# PRD：图片拆分器（Image Splitter）

| 字段 | 值 |
|---|---|
| 产品 | 图片拆分器 — 轻量极简纯 Web 编辑器 |
| 版本 | v1.0 |
| 状态 | 草案 |
| 日期 | 2026-11-22 |

## 1. 产品定位

一个在浏览器里直接使用的图片拆分工具：把一张或多张图片拆成若干切片并批量导出。打开网页即可用，无需安装、无需登录、无需服务器。

核心价值：

- 一张图 → 一组切片（PNG / ZIP）。
- 拆分方式三选一或组合：手动拉框、自动检测、网格切分。
- 多文件并行处理，Tab 切换，一次导出全部产物。

一句话描述：**极简、快速、纯前端的图片切片工具。**

## 2. 目标用户与场景

| 用户 | 场景 |
|---|---|
| 游戏开发者 | 拆 UI 素材图：框选按钮、图标，批量导出透明 PNG 进引擎 |
| 动画师 | 拆 Sprite Sheet：按行列网格切帧，预览动画后打包下载 |
| 前端 / 设计师 | 按坐标清单（JSON）批量截图，或反向导出坐标清单交给开发 |
| 普通用户 | 临时把长图、九宫格、拼图拆成小图，不装任何软件 |

## 3. 功能需求

优先级：P0 必须有，P1 应该有，P2 加分。

### 3.1 文件与 Tab 管理（P0）

- 支持一次拖入或多选打开多个图片文件（PNG / JPG / WebP / BMP / GIF 首帧）。
- 每个文件是一个独立对象，拥有自己的：切片列表、撤销/重做栈、视图状态（缩放/平移位置）、dirty 标记。
- 顶部 Tab 栏：缩略图 + 文件名 + 切片数角标 + dirty 圆点；点击切换，关闭按钮 / 中键关闭；dirty 文件关闭前确认。
- 切换 Tab 时画布、工具参数、列表整体切换，互不串扰。
- 会话恢复：刷新页面后恢复文件列表与切片状态（元数据 localStorage，图片本体 IndexedDB）。

### 3.2 画布查看与导航（P0）

- 滚轮缩放（以鼠标位置为锚点，0.1x–8x），右上角显示当前缩放百分比。
- 空格按住临时平移；平移工具常驻切换。
- 适应窗口 / 1:1 原始尺寸快捷键。
- 点击列表项定位：视口自动缩放平移到该切片并高亮。

### 3.3 手动框选拆分（P0）

- 框选模式：空白处拖拽拉出新切片框；Alt 强制拉框。
- 切片框可点选、多选、拖移、8 向缩放（角点不锁比例）、Delete 删除、一键清空。
- 选中切片的属性表单：名称、类型、X / Y / W / H 数值编辑，实时写回画布。
- 每个切片可勾选「纳入导出」；未勾选仅作参考标记，导出时跳过。
- 切片列表：缩略图 + 名称 + 尺寸；hover 联动画布高亮（其余区域压暗）。

### 3.4 自动检测（P1）

- 三种检测方法：颜色容差（近色连通域）、透明 alpha、参考色吸管（画布取色）。
- 参数：容差、最小面积、外扩边距；调整后实时重算（去抖 300ms）。
- 检测结果落入普通切片框，可继续手动修正，与手动操作共用撤销栈。

### 3.5 网格拆分（P1）

- 输入行列数（1–20），或直接在画布上拖参考线。
- 实时切出全部网格单元；修改行列即时重切。
- Sprite Sheet 模式：按行列播放帧动画预览，确认后逐帧导出。

### 3.6 裁切（P1）

- 裁切模式：拉框选范围，确认后原图被替换为该区域（进撤销栈，可撤销回来）。
- 裁切后所有切片坐标自动平移补偿，不错位。

### 3.7 坐标清单 JSON（P1）

- 导入：按 `{elements:[{id, label, type, coords:[x,y,w,h]}]}` 或 `{ui_elements:[{id, label, bbox_2d:[x1,y1,x2,y2]}]}` 批量生成切片框；支持嵌套 children 展开；坐标若为 0–1000 归一化体系自动换算为像素。
- 导出：当前切片列表写为同构 JSON 下载，供程序消费。
- 解析失败给出行级错误提示，不影响已打开内容。

### 3.8 导出（P0）

- 单张下载：切片列表逐项下载 PNG（从原图像素直接截取，无缩放损耗）。
- 批量导出：
  - 范围可选：全部切片 / 仅勾选「纳入导出」/ 当前类型过滤后的可见集；
  - 形式：逐张下载或打包单个 ZIP（纯前端压缩）；
  - 多文件时每张图的产物归入以文件名命名的子目录；
  - 文件名取切片名，自动去除非法字符、重名加序号。
- 导出过程显示进度（已导出 n / 总数），可取消。

### 3.9 主题切换（P0）

- 浅色 / 深色 / 跟随系统三态，默认浅色。
- 全部颜色走 CSS 变量，切换仅改根节点属性，无闪烁。
- 选择持久化；画布内元素（框描边、角标、遮罩、棋盘格底）同步换肤。

### 3.10 快捷键（P1）

| 键 | 行为 |
|---|---|
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Delete / Backspace | 删除选中切片（输入框内忽略） |
| Space 按住 | 临时平移 |
| Ctrl+O | 打开文件 |
| Ctrl+E | 导出 ZIP |
| Ctrl+Tab | 切换 Tab |
| Alt+拖拽 | 强制拉框 |

所有图标按钮带 title 与 aria-label，焦点环可见。

## 4. UI / UX 规范

### 4.1 视觉基调

- 白底、细边框、大量留白；信息优先，无装饰性元素。
- 每个区块至多一个主动作，用 primary button（白字蓝底实心）；其余动作用 outline / ghost。

色彩 Token（浅色，默认主题）：

| Token | 值 | 用途 |
|---|---|---|
| `--background` | `#ffffff` | 页面与面板底色 |
| `--foreground` | `#0f172a` | 主文字 |
| `--muted-foreground` | `#64748b` | 次要文字、状态栏 |
| `--border` | `#e2e8f0` | 分隔线、描边 |
| `--primary` | `#2563eb` | primary button、激活态 |
| `--primary-foreground` | `#ffffff` | primary 按钮文字 |
| `--accent` | `#eff6ff` | 选中行 / hover |
| `--destructive` | `#dc2626` | 删除、错误 |

深色主题同构替换（`#0f172a / #e2e8f0 / #1e293b / #3b82f6` 等），primary 保持蓝色族。

### 4.2 控件与图标

- 工具按钮 32x32 图标位；输入、开关、滑杆统一 32px 高。
- 图标一律使用线性 SVG 图标库（16 / 20px，stroke 1.5–2），**全 UI 禁止 emoji**——按钮、Tab、状态文本、toast、空态文案中均不得出现 emoji 字符。
- 文案精简：状态栏一行短句（如「已加载 12 个切片」）；空态一句引导 + 一个动作按钮；不出现说明性长段落。

### 4.3 布局

```
┌──────────────────────────────────────────────┐
│ 顶栏：打开 · 撤销/重做 · 主题切换 · 导出      │
│ Tab 栏：[a.png·3] [sheet.png·12·脏] [+]      │
├───────────┬──────────────────────────────────┤
│ 工具面板   │ 画布（缩放/平移/框选）           │
│ 模式/参数  │ 右上角：模式 · 缩放百分比        │
├───────────┴──────────────────────────────────┤
│ 右侧面板：选中属性 / 切片列表 / 帧预览        │
│ 状态栏：状态短句 · 错误提示                   │
└──────────────────────────────────────────────┘
```

- 左右面板可折叠、可拖宽；画布随容器尺寸自适应。
- 窄屏（<1024px）右侧面板收为抽屉。

### 4.4 工程约束

- 组件源码不写多余注释：仅保留公共 API 的 JSDoc 与算法中不可自释的极少量行内说明。
- 单组件文件 < 300 行，超出即拆分（容器 / hook / 展示组件三层）。

## 5. 技术方案（建议）

| 项 | 选型 | 说明 |
|---|---|---|
| 框架 | React 18+ + Vite | 纯静态构建产物 |
| 画布 | fabric.js 或原生 Canvas 自绘 | 对象级框操作成熟 |
| 状态 | useReducer + Context（文件集 / 主题），编辑态留在 per-file hook | 控制重渲染范围 |
| 主题 | CSS variables + 根节点属性切换 | 零成本换肤 |
| 导出 | canvas.toBlob + fflate（ZIP） | 纯前端 |
| 持久化 | localStorage（设置/元数据）+ IndexedDB（图片 Blob） | 会话恢复 |
| 图标 | lucide-react | 线性 SVG，无 emoji |

模块划分：

- `files/`：文件对象模型、Tab 管理、持久化
- `canvas/`：画布初始化、事件（缩放/平移/拉框/选中）、坐标换算
- `slices/`：切片 CRUD、撤销重做、高亮联动
- `detect/`：自动检测 / 网格 / 裁切算法（纯函数，可单测）
- `export/`：PNG / ZIP / JSON 导出
- `components/`：Toolbar、TabBar、SliceList、PropertyForm 等展示组件

## 6. 非功能需求

- **纯 Web**：构建产物为静态文件，离线双击可开；无任何网络请求。
- **性能**：单张 4096x4096、500 切片场景交互 ≥ 30fps；缩略图后台生成并丢弃过期结果；撤销栈上限 100 步。
- **兼容**：Chrome / Edge ≥ 110，Safari ≥ 16，Firefox ≥ 110。
- **健壮**：损坏或超 50MB 的文件跳过并提示，不影响其他 Tab。
- **包体**：首屏 JS gzip ≤ 400KB。

## 7. 验收标准

1. 打开即浅色白底；主题三态切换刷新后保持。
2. 一次拖入 3 张图得到 3 个 Tab，切换/关闭/dirty 确认均正常，切片与撤销栈互不串扰。
3. 手动拉框、编辑、删除、撤销/重做全链路仅作用于当前 Tab。
4. 自动检测参数实时生效；网格行列修改即时重切（P1 达成时）。
5. 「仅导出勾选」时 ZIP 只含勾选切片，文件名合法且无重名。
6. 全 UI 无 emoji；primary button 白字蓝底且每区块至多一个。
7. 断网 + 本地打开构建产物，全部功能可用。
