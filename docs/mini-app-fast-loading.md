# Mini App 快速加载

设置 → 通用 → Mini App 快速加载：生产环境默认开启，开发环境默认关闭，偏好保存在当前浏览器。
预览右上角的开关按应用保存，优先于总开关；未操作的应用跟随总开关。
切换后自动重新加载应用，插件、Agent、主题和宿主 UI 仍沿用原有运行环境。

## 生成产物

在 Flow Spaces 仓库执行：

```sh
pnpm mini-app:build "/absolute/path/to/mini-app"
```

命令读取应用根目录 `manifest.json` 的 `mainFile`，将 `src/` 中的 React 组件打包为
`dist/index.cjs`（默认导出组件，可选 `dist/index.css`）。不要使用包含独立 React 实例或
自行调用 `createRoot` 的 SPA 产物。其他构建工具也可以生成符合此约定的 CommonJS bundle。
CSS 应使用内联资源或绝对资源 URL；不支持依赖 dist 相对 URL 的资源包。

快速模式只读取该 bundle 和可选 CSS，跳过源码清单、逐文件预读及浏览器 Babel 编译。
编辑页额外读取一个源码入口，为 Agent 保留编辑上下文。
没有产物、产物为空或连接旧服务器时，自动回退源码模式；HTML 应用继续使用原有加载方式。

## 更新应用

源码模式支持现有自动预览。快速模式使用已经构建的版本：修改源码后重新执行构建命令，
再点击预览右上角的刷新按钮。若需要实时编辑，关闭当前应用的快速加载开关。
发布到商店时应将根目录的 `dist/` 一同包含在安装文件清单中。
